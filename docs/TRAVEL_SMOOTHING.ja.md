# ペンを上げた移動の二次曲線

**G-code Preview → PATH PLANNING → Smooth pen-up travel (quadratic)**。既定はオフです。素材を CLI で変換する場合は `--smooth-pen-up`。設定はプロジェクトに保存され、これまでのプロジェクトはオフで開きます。

- 隣接する描画線の方向から意味のあるふくらみが決まる場合だけ、ペンを上げた位置から次の線の始点までを緩い二次 Bézier 曲線に置き換えます。最初の XY 移動、描画線、送り、Z、待機の順は変わりません。
- ふくらみは理論上最大 0.75 mm（丸め前）。最大 8 本の `G1` に分け、丸め前の分割近似誤差は最大 0.02 mm、丸め後の最短区間は 0.4 mm。範囲外、短距離、許容コマンド数不足なら直線を維持します。
- **G-code Preview → Refresh from current job → Show pen-up moves** で実際のコマンドを確認できます。空走と描画で XY は同じです。治具やペンの三次元干渉は判定しません。ファームウェアの加速度やジャークを変更する機能ではなく、実機で動きが滑らかになるかは未確認です。

## 機種との関係

- **EasyThreed K9**：既定空走速度 40 mm/s を変更しません。実測 Z と手動原点復帰が必要です。
- **Voxelab Aries**：実験的な G-code 出力です。実測 Z と校正確認が必要で、未確認の `G4` は許可しません。
- **Bambu Lab P1S**：配置確認専用のままです。この機能で P1S の G-code 出力は有効になりません。
