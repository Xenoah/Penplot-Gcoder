# Penplot-Gcoder v0.10.0 — 線画抽出と色別ハッチ

スキャンの背景ムラや点ノイズに埋もれた細線を抽出する **Clean line art** と、実際にペンで描ける **Color hatch** を追加しました。

- Clean line art: 局所背景補正、点ノイズ除去、中心線抽出。半径・濃さ・点の大きさをプレビューで調整できます。従来の Outline / Centerline は Threshold (classic) に残っています。
- Color hatch: 最大2〜8色のパレットを推定し、色ごとに独立した編集可能レイヤーを生成します。透明な穴と色境界を保ち、白背景の除外、ハッチ間隔・角度・輪郭の有無を変更できます。
- Export colors: 同一の紙座標で `P01.GCODE` などの色別ファイルと `PENS.txt` を新しいフォルダーに保存します。K9 などの単ペン機はファイル完了後に手動で交換します。自動交換・HOME 命令は追加しません。
- 表示と保存: 色を編集画面と G-code の実コマンドプレビューに反映。全非表示を挟んだ表示切り替えと、保存・再読込による位置ずれを防ぎます。
- CLI: `--raster clean|color`、`--palette`、`--colors-dir` などを追加。GUI も `penplot-studio FILE` で画像やプロジェクトを開けます。

新しい設定を使うプロジェクトは形式 v4 です。従来設定だけなら v2/v3 を維持し、v1〜v3 の読み込み、選択レイヤーだけの移動・拡縮、既存の K9 設定は維持します。

## 検証と制限

合成 PNG で背景ムラ・1画素の薄い T 字・点ノイズ・透明・穴・隣接する赤青・黒線を検査。全色と個別色の実際の G-code の XY、保存・再読込、全非表示と再表示、色レイヤーの拡縮を回帰テストしています。ローカル Linux は fmt、clippy、全機能130テスト、ヘッドレス75テスト、release ビルドが成功しています。

Linux の実画面でも線画取り込みと3色レイヤーを操作確認しました。ただし、この作業環境から画像ファイルを取得できず、v0.10.0 の実画面スクリーンショットは未添付です。README の旧版スクリーンショットを当該版として流用していません。素材は同梱スクリプトで生成した合成画像だけです。

Windows の実 GUI 操作、Linux のネイティブファイルダイアログ（デスクトップポータル未導入）、実機の描画・ペン交換・位置合わせは未検証です。Color hatch は中心線化ではなく領域のハッチ塗りです。ペン幅やにじみは考慮せず、細い領域に対してハッチ間隔が広すぎると線が入りません。
