# バケツでパターン塗り（v0.11.0）

**Edit → バケツ塗り / Bucket fill** で、閉じた領域の内側をクリックします。選んだ領域が、水玉・斜線・クロスハッチングを持つ独立したレイヤーになります。塗りは単なる表示色ではなく、実際にペンがたどる経路です。

1. SVG/DXF または取り込んだ画像の輪郭、Box/Ellipse/Line などで閉じた領域を用意します。同梱の `examples/bucket-card.svg` でも試せます。
2. Edit の **Bucket fill / バケツ塗り** を選びます。左側で **水玉 / Polka dots**、**斜線 / Diagonal lines**、**クロスハッチング / Cross-hatching** と **濃度・密度 (%) / Density** を選びます。
3. 内側をクリック。穴は塗らず、閉じた境界の内側だけに模様を作ります。別々に描いた線の接続、交点、隣接領域の共有辺にも対応します。隙間を自動的につなぐことはありません。
4. スライス・出力前に **塗りプレビュー（グレー） / Grayscale fill preview** で仕上がりを確認します。白い紙の上に、出力と同じ経路を指定ペン幅の黒線で表示します。密度を上げるほど模様が増えて濃く見えます。単なる灰色のベタ表示ではありません。
5. 追加済みの塗りレイヤーを右側で選び、パターン・密度・ペン幅・水玉直径・角度を再調整できます。すでに塗った領域をもう一度バケツでクリックすると、その塗りを更新します。Undo/Redo、Delete、表示切り替え、選択レイヤーの移動・拡縮に対応します。
6. 確認後、**1. Generate G-code → 2. Preview → 3. Export** へ進みます。機械設定と K9 の動作設定は変わりません。

## 密度とペン幅

密度は1〜100%の相対値です。ペン幅を基準に線や水玉の間隔を変えます。100%は幾何学的な面積比約75%を目安とする最も密な設定で、紙を完全な黒にする指示ではありません。クロスハッチは2方向の重なりも考慮した間隔です。実際の濃淡はペン・紙・にじみで変わります。

ペン幅はプレビューと間隔計算に使います。v0.12.0以降の新しい塗りでは「ペン幅より細い部分を省く」が初期オンで、斜線・クロスハッチを外周・穴からペン半径ぶん離します。旧プロジェクトの塗りは自動変更せず、必要に応じてオンにしてください。[詳細](PEN-WIDTH.ja.md)。既存の Z・速度・圧力設定は変更しません。線画全体や塗り領域を拡大しても、パターンの間隔とペン幅は紙上の mm を維持します。

水玉は外周だけの円ではなく、ペン幅で内側を埋める短い連続らせんとして描きます。水玉全体が領域に収まる場所だけに配置します。穴や境界に接する水玉は省略し、小さすぎる領域では密度や水玉直径の調整が必要です。新しい点打ち・交換・HOME 命令は挿入しません。

## 保存と既存機能

塗りレイヤーは境界のコピーとパターン設定を `.penplot` に保存する形式 v5 です。元画像がなくても再開でき、CLI の `penplot convert --calibrated -o PLOT.GCODE saved.penplot` も GUI と同じ経路を生成します。元の線画を後から変形・削除しても塗りは独立して残るため、線画を変えた場合は塗りを作り直してください。

v1〜v4 の読み込みと、パターンを使わない文書の従来形式を維持します。Threshold／Clean line art／Color hatch、色別出力、文字、K9 の校正・開始設定・垂直リフトは変更しません。Min image stroke のノイズ除去はバケツの水玉を削除しません。

境界は最大12,000線分・交点探索800万比較・分割後40,000辺までです。複雑すぎる画像では輪郭を簡略化してください。ペンの太さによる実物のにじみや実機の位置精度は保証せず、実機動作は未検証です。
